# 💱 Conversor de Moedas

Um projeto desenvolvido com **HTML, CSS e JavaScript** para praticar manipulação do DOM, funções, objetos, validação de dados e operações matemáticas.

## 🚀 Funcionalidades

- 💰 Inserção do valor para conversão.
- 🌎 Seleção da moeda de origem e destino.
- 🔄 Conversão entre Real (BRL), Dólar (USD), Euro (EUR) e Libra (GBP).
- ✅ Validação dos valores informados.
- 📊 Exibição do resultado com duas casas decimais.

## 📚 Conceitos praticados

- Funções em JavaScript.
- Variáveis com `const`.
- Objetos e propriedades.
- Condicionais com `if`.
- Validação com `isNaN()`.
- Conversão de texto para número com `parseFloat()`.
- Manipulação do DOM com `getElementById()`.
- Uso de `.value` e `.innerText`.
- Template strings.
- Formatação numérica com `.toFixed(2)`.

## ⚙️ Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
4. Informe o valor, selecione as moedas e realize a conversão.

## ⚠️ Observação

Este projeto utiliza taxas de câmbio fixas para fins de estudo. Os valores não representam cotações em tempo real.

Praticar os fundamentos do desenvolvimento web e evoluir na programação JavaScript por meio de projetos práticos.
